# File Organizer - Python Automation Tool

A Python automation tool that automatically organizes files into categorized folders based on their file type.

## what it does
-Scans a folder for all files
-Detects file type by extension
-Automatically moves files into:
  -  Images/ → .jpg .jpeg .png .gif
  -  Documents/ → .pdf .docx .txt
  -  Music/ → .mp3 .wav
  -  Videos/ → .mp4 .mov
  -  Others/ → everything else
- Logs every action with a timestamp

##  How to Use

1. Clone the repo
2. Set the folder path in organizer.py
3. Run the script:
   python organizer.py
